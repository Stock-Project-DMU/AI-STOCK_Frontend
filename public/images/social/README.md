# Social provider images

Original PNG assets downloaded from each provider's official design resources.
Used to identify the current login provider in the My Page profile panel.

- `google.png`: https://developers.google.com/static/identity/images/g-logo.png
  - Guide: https://developers.google.com/identity/branding-guidelines
- `kakao.png`: `Kakao Login/PNG @4x/kakao_login_light.png` from https://developers.kakao.com/tool/download/Kakao%20Login.zip
  - Resources: https://developers.kakao.com/tool/resource/login
- `naver.png`: `NAVER_login_KR/NAVER_login_Light_KR_green_icon_H56.png` from https://developers.naver.com/inc/devcenter/downloads/bi/NAVER_login_KR.zip
  - Guide: https://developers.naver.com/docs/login/bi/bi.md

Files retain the original artwork and colors. Render with `object-contain` to preserve their aspect ratios.
